设计初衷 · 4 条核心需求 我想开发一个适用于任何cli agent的酒馆角色扮演skill，存放于~/.agents/skills/ 当前工作目录就视为一个聊天记录的目录。也就是一个工作目录=一个对话。角色卡、预设、世界书、聊天记录以规范形式在工作目录组织好。 不是每个角色卡都有状态栏。前端状态栏直接一律转为mvu状态栏，无法完美转换允许舍弃部分状态栏换取稳定性并告知用户。预设依据json开关加载并可控。 以agent自带记忆为主，skill的memory记忆（摘要和完整全文两个目录）为辅，优先查阅摘要，需要细节再去读取全文，在消耗最少token下保证最大记忆。

架构边界：保持不变的约束与 v1 明确不做的内容.

  • 全套运行时脚本仅使用 Node.js v18+ 标准库，零外部 npm 依赖，Windows 与 POSIX 通用.
  • 仅在玩家选定的对局目录读写存档，绝不污染 ~/.agents/skills/tavern-bard/ 或篡改 CLI 工具配置.
  • 不运行网页 DOM 或卡片自带的 tavern_helper JS 脚本，纯文学优先.
  • 开发仓库中的 tests/、docs/ 与 示例资源/ 不会随部署复制到全局目录.
